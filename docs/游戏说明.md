## 1. 游戏大厅

### 1.1 七张游戏卡片

| 卡片 | 副标题 | 一句话玩法 |
| --- | --- | --- |
| SNAKE | 经典贪吃蛇 · 四档难度 | 吃食物变长，别撞墙别咬自己 |
| TETRIS | 俄罗斯方块 · 无尽升级 | 消行得分，冲击更高等级 |
| PAC-MAN | 吃豆人 · 追逐与反杀 | 吃光豆子，能量豆反杀幽灵 |
| BEE | 小蜜蜂 · 冲刺/成就/Boss 战 | 击落蜂群，每 5 波决战 Boss |
| PINBALL | 3D 弹球 · 挑战重力 | 挡板接球，点亮目标灯抢头奖 |
| 华容道 | 六布局 / 每日一题 / 评级 | 移动棋子助曹操出逃，冲击 S 级 |
| 1024! | 数字合并 · 合出 1024 获胜 | 滑动合并数字，合出 1024 即胜 |

每张卡片带实时预览动画与 **BEST 最高分徽标**（华容道显示「BEST N 步」，其余显示最高分，无纪录显示 `BEST --`）。

### 1.2 大厅功能

- **TOTAL 总分条**：六款计分游戏（贪吃蛇/俄罗斯方块/吃豆人/小蜜蜂/弹珠台/1024）历史最高分之和；从游戏返回大厅时若总分上涨，播放破纪录号角。
- **奖杯墙**：右上角「🏆 奖杯墙」按钮点开聚合面板，汇总六款游戏共 25 项成就的解锁进度（每游戏一行 + 总进度环），Esc 或点击面板外关闭。
- **游玩时长角标**：每张游戏卡片显示累计游玩分钟（页面可见期计时），挂机不算、关闭页面不丢。
- **上次游玩角标**：最近启动的游戏卡片带角标，回到大厅时焦点自动落在这张卡上，按空格即可续玩。
- **键盘导航**：方向键在卡片网格间移动焦点（宽屏 4 列 / 窄屏 2 列），**空格** 打开游戏（回车保留给投币专用）。
- **手柄支持**：插入 USB / 蓝牙手柄即插即用——方向键导航、启动游戏与各游戏方向 / AB 键自动映射（映射表见 §9），无需任何设置；连接 / 断开有顶部提示条，拔出或切页自动释放按键不卡键。
- **音效控制**（大厅与游戏页右上角同一套）：
  - **单击**声音按钮：一键静音 / 恢复（快捷键 **M**），档位无损；
  - **长按或右键**：展开音量面板，「♪音乐 / ✦音效」各 4 档独立调节；
  - 设置全页面间实时同步，刷新后自动恢复。
- **全屏**：右上角全屏按钮或快捷键 **F**，等比缩放游戏区域。
- **投币开机**：首次进入大厅为**黑白灰度待机态**，游戏卡片锁定；「INSERT COIN · SELECT YOUR GAME」提示语与投币口保留霓虹色彩，指引投币。此时**点击屏幕任意处**或按**任意键**（音效 / 全屏按钮除外）即投币点亮——金币在屏幕中央放大展示（直径约 133px、悬停约 1.15 秒），币缘弧形环排「姜米条条的 / 像素街机厅」站名铭文（仿纪念币版式，看清币面后末段蓄力迸发一圈金色光环），随后划出优美抛物线（约 1 秒）逐渐缩小、自旋一周飞入投币口（落口瞬间投币口轻震吞币、迸出金光圈与四溅金火花，并伴金属落箱声），金币落入投币口吞币后，大厅约 3.0 秒分层通电逐层亮起——层次感来自「离散事件 + 层间留白」，每层快速脉冲式点亮、前层亮完后层才接棒：环境电源层两段脉冲点亮（继电器吸合 → 电压暂降 → 全压过曝 → 回落定色），随后副标题「啪」地亮起，ARCADE 标题霓虹灯管「亮-熄-亮-熄-亮」三抽搐点火（点燃的同时总分条通电），最后七张游戏卡片自左向右每张错峰 0.15 秒快速点亮、节拍清晰可数（每张伴随一道电弧掠过）、卡片解锁可选。点亮后仍可**点投币口**或按**回车**重复投币，重温金币演出（纯装饰，可连点）；回车为投币专用键，不会误启动选中的游戏，投币后的金币飞行与点亮过渡期（合计约 6.0 秒）内点击卡片只算投币、不会立刻进游戏。任意键不含 Ctrl / Alt / Win 组合键、Tab 与 F 功能键等浏览器快捷键。音效 / 全屏按钮灰度期间照常可用，外观与点亮后完全一致。
- **待机吸引模式**：大厅闲置 20 秒自动进入街机式演示——卡片轮流聚光（每 3.4 秒换一张），顶部降下 DEMO 横幅；按任意键 / 动鼠标 / 触摸立即退出。
- **音频律动灯带**：点亮后环绕灯带与投币口随声音实时律动——鼓点越猛灯带越亮越艳，高音上扬时四色霓虹整体流转，投币口随低音脉冲闪亮；静音或无声时灯带自动回暗（音乐真响灯带真亮），「减少动态效果」开启时不启动。
- **开 / 关演出**：点卡片以覆盖层方式打开游戏（不跳页），先播 LOADING 霓虹字 + 流光进度条，加载完成交叉淡入；关闭时播放 CRT 关机坍缩演出，游戏画面最后一帧截图缩放飞回对应卡片点亮辉光（关气回流缩略），随后刷新 BEST。

### 1.3 进度自动保存与恢复

七款游戏统一支持**进度镜像快照**：

- **保存时机**：点击覆盖层左下角「←」图案返回按钮（悬停提示「返回游戏厅」）、关闭/刷新页面时自动保存当前棋局。
- **恢复**：再次进入同一游戏时自动恢复上一次进度（提示「已恢复上次进度」），接着玩；
- **清档时机**：Game Over 结算、通关、主动重开会清除快照，下次从头开始。

> 无需任何手动存档操作，随时离开、随时续玩。

## 2. 贪吃蛇 SNAKE

**简介**：经典贪吃蛇，四档难度，金苹果与连击加成让刷分更有讲究。

| 项目 | 说明 |
| --- | --- |
| 难度 | 无敌 / 简单 / 中等 / 困难（速度与单食分值不同；无敌档撞墙穿墙、撞身穿过，不会结束） |
| 进度快照 | 支持，随时离开随时续玩 |
| 成就 | 3 条（C 键查看） |

**操作键位**

| 按键 | 功能 |
| --- | --- |
| ↑↓←→ / WASD | 移动 |
| 空格 | 暂停 / 继续 |
| C | 成就面板 |

**玩法与得分**

- 普通食物 = 难度基础分（简单 5 / 中等 10 / 困难 20）；
- **金苹果** = 基础分 ×5，存在 5 秒（带倒计时环），吃普通食物后有 22% 概率刷新；
- **连击加成**：3 秒内连续进食，连击 ≥2 时得分 ×(1 + 0.5 × (连击 − 1))；
- 每吃 5 个食物提速一档（STATS 显示速度等级），越吃越快；
- **每日目标**：每天一个目标长度（15~30 节），HUD「今日」行实时显示已达长度；当日达成记录当日标记并有金色庆祝演出；
- **自适应 BGM**：蛇身长到 15 节起，背景音乐自动叠加一层低音鼓点声部烘托危险氛围（15 恰为每日目标区间下限——鼓点响起即说明逼近今日目标），游戏结束重开后鼓点层自动消退；
- 撞墙或咬到自己即结束。

**成就**：百分俱乐部（单局 100 分）· 长蛇盘踞（长度 30 节）· 连击好手（连击 ×5）

## 3. 俄罗斯方块 TETRIS

**简介**：完整 SRS 旋转系统 + Hold 暂存 + T-Spin / B2B / All Clear 计分三件套，消行冲击无限升级。

| 项目 | 说明 |
| --- | --- |
| 难度 | 无敌 / 简单（×1）/ 中等（×2）/ 困难（×3，得分倍率与下落速度不同；无敌档堆到顶清空棋盘继续） |
| 进度快照 | 支持（含棋面、当前方块、下一个队列、Hold） |
| 成就 | 3 条（V 键查看） |

**操作键位**

| 按键 | 功能 |
| --- | --- |
| ←→ / AD | 左右移动 |
| ↓ / S | 软降（+1 分/格） |
| 空格 | 硬降（+2 分/格） |
| ↑ / W / X | 顺时针旋转 |
| Z | 逆时针旋转 |
| C / Shift | Hold 暂存（每次落子限一次） |
| P | 暂停 / 继续 |
| V | 成就面板 |

**玩法与得分**（消行分 × 等级 × 难度倍率）

- 消行：1 行 100 / 2 行 300 / 3 行 500 / **TETRIS（4 行）800**；
- **T-Spin**：400~1600（Mini 减半）；**B2B**（连续 TETRIS / T-Spin）再 ×1.5；
- **All Clear**（全消）：800~2000 大奖；连消每段 +50 × 连击 × 等级；
- NEXT 预览 3 块、7-bag 随机、锁定延迟 500ms（移动/旋转可重置，上限 15 次）；
- 每消 10 行升 1 级，方块下落加速。

**成就**：行云流水（累计消 40 行）· TETRIS!（单次消 4 行）· 高速运转（等级达 5）

## 4. 吃豆人 PAC-MAN

**简介**：原味迷宫追逐——四幽灵有性格、有相位，能量豆一转攻守易势。

| 项目 | 说明 |
| --- | --- |
| 难度 | 无敌 / 简单（能量豆 10 秒）/ 中等（8 秒）/ 困难（6 秒）；幽灵速度与得分倍率随档变化 |
| 进度快照 | 支持（含豆子、恐惧状态、水果、角色位置） |
| 成就 | 3 条（C 键查看） |

**操作键位**

| 按键 | 功能 |
| --- | --- |
| ↑↓←→ / WASD | 移动 |
| P | 暂停 / 继续 |
| C | 成就面板 |

**玩法与得分**

- 豆子 10 分、能量豆 50 分（×难度倍率）；
- **反杀**：能量期内每吃一只幽灵 200 / 400 / 800 / 1600 递增；
- **水果**：每关吃到 70 / 170 颗豆时出现，存活 9 秒，基础 100 × 关卡数（封顶 1000）；
- 19×21 迷宫，四幽灵按「巡逻 5 秒 / 追击 18 秒」相位循环，出屋各有先后，随关卡提速；
- **自适应 BGM**：幽灵进入「追击」相位时背景音乐自动叠加低音鼓点声部（危险逼近），转回「巡逻」相位鼓点层自动消退——听鼓点即可预判攻守节奏；
- 初始 3 命，累计每 10000 分奖 1 命（每局一次）；吃光全部豆子进入下一关。

**成就**：颗粒归仓（单局吃光豆子）· 四连反杀（单次能量期吃 4 只）· 豆豆大胃王（累计吃 500 颗）

## 5. 小蜜蜂 BEE

**简介**：Galaxian 类固定射击——蜂群横移下压、蜜蜂俯冲投弹，每 5 波 Boss 三段式入场决战。

| 项目 | 说明 |
| --- | --- |
| 难度 | 无敌 / 简单（4 命）/ 普通（3 命）/ 困难（2 命），敌弹速与攻击频率不同 |
| 进度快照 | 支持（含波次、蜂群、弹药、道具、Boss 状态） |
| 成就 | 10 条（C 键查看），结算面板给 S/A/B/C 评级 |

**操作键位**

| 按键 | 功能 |
| --- | --- |
| ←→ / AD | 左右移动 |
| 空格 | 射击 |
| Shift | 冲刺（短暂无敌 + 残影，冷却 1.6 秒） |
| P | 暂停 / 继续 |
| C | 成就面板 |

**玩法与得分**

- 连续击杀积累连击：窗口 2.5 秒，每 5 连击得分倍率 +1（最高 ×5），超时或受击清零；
- 击落 9% 概率掉落道具，落出屏幕消失（可被磁铁吸引）。

**七种道具**

| 道具 | 效果 |
| --- | --- |
| 火力 W | 单发 → 双发 → 三向散射 |
| 护盾 S | 挡 1 次伤害 |
| 1UP ♥ | 奖励 1 命（上限 5） |
| 炸弹 B | 全屏清弹 + 范围伤害（对 Boss 8 伤） |
| 时停 T | 冻结敌阵 4 秒 |
| 磁铁 M | 6 秒内吸引场上道具 |
| 激光 L | 5 秒贯穿光柱 |

**机制要点**

- 蜂群 8×4 横移、碰壁下压，每波提速 12%；混编精英蜂（2 血）、分裂蜂（死后裂两只小蜂）、自爆蜂（俯冲贴近引爆环形弹幕）；
- 第 3 波起概率触发**事件波**：俯冲潮（俯冲频率大增）或精英阵（全员精英）；
- **每 5 波 Boss 战**：警告横幅鸣响 → 缓降入场 → 落地冲击震屏；击败奖励 500 + 50 ×（波次 − 1）并掉落道具；
- **自适应 BGM**：Boss 战全程（警告横幅响起即进入）背景音乐自动叠加低音鼓点声部，击败 Boss 后鼓点层自动消退；
- 每 10000 分奖励 1 命（上限 5）。

**成就**：初战告捷 · 百人斩 · 十连击 · 连击大师 · 弑君者（击败 Boss）· 十波坚守 · 万分俱乐部 · 爆破专家 · 幻影步（冲刺达人）· 完美防御（一波未掉命通关）

## 6. 3D 弹球 PINBALL

**简介**：伪 3D 视角弹球台——蓄力发球、点亮目标灯、清板抢 JACKPOT 头奖。

| 项目 | 说明 |
| --- | --- |
| 难度 | 无敌 / 简单（×1）/ 中等（×2）/ 困难（×3）：重力、挡板长度、得分倍率不同 |
| 进度快照 | 支持（含多球、目标灯、连击、Jackpot 状态） |
| 成就 | 3 条（C 键查看） |

**操作键位**

| 按键 | 功能 |
| --- | --- |
| ← / A | 左拍板 |
| → / D | 右拍板 |
| 空格（按住） | 蓄力发球（约 0.9 秒充满，力度决定初速） |
| 空格 / P | 暂停 / 继续 |
| C | 成就面板 |

**玩法与得分**（×难度倍率，再 × 连击倍率）

- 弹柱 60 / 弹射器 25 / **目标灯 150**；
- 点亮全部目标灯触发**清板**：+2000、重置灯、武装 Jackpot、并奖励 2 球（同场最多 3 球）；
- 清板后击中中央弹柱 = **JACKPOT 5000**；
- 两球相撞 30 分（快速对撞才计分）；
- **连击倍率**：2 秒窗口内每 3 次得分倍率 +1，最高 ×5；
- 共 3 球（含首发）；多球期间全部落底才失球。

**成就**：头奖时刻（触发一次 JACKPOT）· 三球齐飞（同场 3 球）· 两万分俱乐部（单局 20000）

## 7. 华容道 KLOTSKI

**简介**：经典滑块益智——六布局、每日一题、BFS 求解器提示与自动演示，冲击 S 级评级。

| 项目 | 说明 |
| --- | --- |
| 难度 | 新手（提示 + 撤销无限）/ 进阶（默认，提示每局 3 次）/ 大师（禁用提示与撤销） |
| 进度快照 | 支持（布局、难度、步数原样恢复） |
| 记录 | 按难度 + 布局分别记录最少步与最佳评级（无成就系统） |

**操作键位**

| 按键 | 功能 |
| --- | --- |
| 点击 / 拖动 | 选中并移动滑块 |
| 方向键 / WASD | 移动选中块 |
| U | 撤销 |
| R | 重开 |
| H | 提示（高亮推荐棋子与滑动方向） |
| 空格 | 暂停（失焦自动暂停，计时冻结） |
| P | 演示 BFS 最佳解（演示通关不记成绩不评级） |
| 1~6 | 切换布局 |

**玩法要点**

- 六个经典布局：横刀立马 · 指挥若定 · 捷足先登 · 过五关 · 近在咫尺 · 兵临城下；
- 目标：将曹操（2×2 大块）从底部开口移出；
- **评级**：实际步数 ÷ 最优步数——≤1.15 **S** / ≤1.4 **A** / ≤1.8 **B** / 其余 C；使用提示会封顶评级（1~2 次最高 A，3 次以上最高 B）；
- **每日一题**：按钮带金色「今」角标，每日固定一题，当日通关记录成绩（重复通关取更优步数）；
- 求解器运行在后台 Worker，提示与演示全程不卡顿。

## 8. 1024! 数字合并

**简介**：滑动合并数字，合出 1024 即胜利——撤销救场、连击加分、里程碑全屏演出。

| 项目 | 说明 |
| --- | --- |
| 难度 | 简单 5×5 / 普通 4×4（默认）/ 困难 3×3；目标都是合成 1024 |
| 进度快照 | 支持（每步有效滑动与撤销后立即落盘） |
| 成就 | 3 条（C 键查看） |

**操作键位**

| 按键 | 功能 |
| --- | --- |
| 方向键 / WASD（或触屏/鼠标拖动滑动） | 滑动合并 |
| Z / U | 撤销（简单 5 次 / 普通 3 次 / 困难 1 次，结束后仍可撤销救回死局） |
| P / 空格 | 暂停 / 继续 |
| R | 重开 |
| C | 成就面板 |

**玩法与得分**

- 每次合并得「合并结果值」分（如 64+64 = +128 分）；
- **连击奖励**：连续有合并的步数积累连击，每级追加奖励分；
- 一步多次合并弹出 DOUBLE! / TRIPLE! / QUAD! / PENTA! / MEGA! 喝彩；
- **里程碑演出**：首次合成 128 / 256 / 512 / 2048 / 4096 触发粒子大爆发 + 冲击波 + 闪光（≥2048 追加全屏烟花秀）；
- **胜利**：首次合成出 1024 弹出胜利面板，可选择「继续挑战」冲更高数字。
- **每日挑战**：当日未达成时开局自动进入每日挑战——本局方块生成序列按日期固定，同一天每局谜题相同；HUD 显示金色「每日挑战」徽章，当日首次合出 1024 即记达成并庆祝；

**成就**：初窥门径（合成 256）· 巅峰达成（合成 1024）· 百合并（单局合并 100 次）
