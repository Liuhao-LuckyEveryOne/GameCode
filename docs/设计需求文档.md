## 1. 背景与目标

**背景**：玩家需要一种"打开就能玩"的休闲街机体验——无需下载安装、无需注册账号、无需联网，短时段即可获得完整的一局乐趣与成长反馈（分数、纪录、成就）。

**产品决策**：做一个浏览器本地运行的像素风街机厅：一个大厅页聚合七款原创街机游戏，以复古 CRT 视觉、八位机合成音效与演出化反馈营造街机厅氛围，全部数据留存于玩家本机。

**预期可观察结果**：

- 打开页面即可游玩，断网可完整体验全部功能；
- 每款游戏保留最好成绩（计分游戏为最高分；华容道为最少步纪录与最高评级），大厅可见各游戏 BEST 与总分；
- 对局中途离开再回来，能从上次局面继续玩；
- 达成成就、打破纪录有明确的即时提示与演出。

**设计原则**：

| 原则 | 可观察含义 |
| --- | --- |
| 零门槛 | 无安装、无注册、无网络依赖，打开即玩 |
| 街机氛围 | CRT 质感、霓虹视觉、合成音效、演出化反馈（开场/结算/破纪录/成就） |
| 公平留存 | 成绩、成就、进度仅存于玩家本机；清除浏览器站点数据即完全重置 |
| 键盘优先 | 全部核心玩法与大厅导航均可仅用键盘完成 |

## 2. 范围

**进入条件**：玩家使用现代桌面浏览器打开大厅页。

**P0 核心旅程**：大厅卡片导航 → 启动任一游戏 → 完整游玩一局（可暂停）→ 结算（得分 / 纪录 / 成就）→ 返回大厅并看到 BEST 与总分更新。
最重要的恢复路径：对局中途离开（返回大厅或关闭页面）后再次进入，从进度快照续玩（见 R1）。

**P1 支持能力**：总分条、上次游玩角标、待机吸引模式、投币开机（灰度待机 + 投币点亮，H8）、开关机与卡带演出、成就系统、成就奖杯墙与游玩时长统计（H9）、评级（蜂群射击 / 华容道）、每日一题（华容道）、每日挑战（贪吃蛇 / 1024）、演示模式（华容道）、全屏、音量面板。

**明确排除**（避免范围歧义）：账号体系、云存档、联网排行榜、多人对战、内购；移动端触屏体验不在本版承诺范围（华容道额外支持指针拖拽为唯一例外）。

## 3. 产品模型与核心旅程

**角色**：玩家（唯一角色，无权限分层）。

**核心对象**：

| 对象 | 定义 | 生命周期 |
| --- | --- | --- |
| 对局 | 玩家在某款游戏中一次进行中的游玩 | 开始（新局或续玩）→ 进行 ⇄ 暂停 → 终结（Game Over / 通关 / 主动重开） |
| 纪录 | 每游戏的最好成绩（计分游戏为最高分；华容道按 难度×布局 分记最少步与最高评级） | 只增不减，跨局持久 |
| 成就 | 各游戏定义的一次性荣誉（华容道不设成就） | 达成后持久 |
| 进度快照 | 对局进行中的局面存档，用于断点续玩 | 随对局写入 / 恢复 / 清除（R1） |
| 音效偏好 | 静音开关 + BGM / SFX 双通道档位 | 持久，大厅与全部游戏一致（H4） |

**核心旅程**：

```text
打开大厅（开机演出）→ 投币点亮（灰度待机，点击任意处 / 任意键，见 H8）
  └─ 卡片导航（方向键 / 鼠标）→ 确认启动（卡带过渡）
       └─ 存在本游戏快照？
            ├─ 是 → 恢复局面，提示「已恢复上次进度」→ 续玩
            └─ 否 → 新开局
游玩 ⇄ 暂停（空格手动 / 窗口失焦自动）
  ├─ 对局终结（Game Over / 通关 / 重开）→ 结算（得分·纪录·成就）→ 快照清除
  └─ 中途返回大厅 / 关闭页面 → 自动写入快照
返回大厅 → CRT 关机过渡 → 刷新 BEST / 总分 / 上次游玩角标
```

## 4. 功能需求

> 七款游戏共享的横切规则（续玩、暂停、结算、成就、音效、减动效）统一定义于 [§5 共享规则](#5-共享规则与例外)，各章节按 R1~R6 编号引用，仅描述游戏特有差异。各游戏完整键位表见《游戏说明》，本文不重复罗列。

### 4.1 游戏大厅

#### H1 游戏卡片与导航

- **目的**：让玩家在七款游戏中快速定位并启动目标游戏。
- **布局**：星空 CRT 背景上一屏卡片网格；每张卡片展示游戏名、一句话副标题、封面立绘与该游戏 BEST（最高分或最高评级）。
- **触发与处理**：方向键在卡片网格间移动焦点，空格确认启动（回车保留给投币，见 H8）；鼠标悬停、点击等价。焦点切换与确认均有音效反馈，且每款游戏拥有专属的选卡签名音。
- **结果与状态**：确认后播放卡带式过渡进入游戏页（见 H7）；卡片具备默认 / 悬停 / 选中 / 上次游玩角标（H3）四种可见状态。

#### H2 总分条

- **规则**：大厅展示 TOTAL 总分，数值 = 六款计分游戏（贪吃蛇、俄罗斯方块、吃豆人、蜂群射击、弹珠台、1024）最高分之和；**华容道不计分、不参与合计**。
- **反馈**：任一构成游戏破纪录后返回大厅，总分随之增长，伴随破纪录号角音演出。

#### H3 上次游玩与初始焦点

- 上一次运行的游戏卡片带专属角标；
- 大厅加载完成时，初始键盘焦点自动落在该卡片，便于"一进大厅就接着玩"。

#### H4 全局音效控制

- **单击 M（或音效控件）**：一键静音 / 取消静音。静音为无损开关——静音不改动档位，恢复后还原原档位。
- **长按**：弹出音量面板，BGM 与 SFX 双通道独立调节，各 0~3 档。
- **一致性**：音效状态持久保存，并在大厅与全部游戏间自动保持一致（含嵌入模式下的父子页同步）。

#### H5 全屏

- **触发**：F 键切换全屏 / 退出全屏。
- **一致性**：全屏状态同步至游戏内，进出游戏不丢失。

#### H6 待机吸引模式（Attract Mode）

- **触发**：大厅连续 20 秒无任何输入自动进入。
- **行为**：以约 3.4 秒一轮的节奏聚光轮播各游戏画面，模拟街机厅招揽演示。
- **退出**：任意按键或指针输入立即退出，恢复可操作的大厅状态。

#### H7 开关机演出与卡带过渡

- **开机**：首次打开大厅播放 CRT 通电演出（LOADING 霓虹 + 流光）。
- **关机**：从游戏返回大厅时播放 CRT 关机坍缩过渡，随后刷新各卡片 BEST 与总分。
- **卡带过渡**：启动游戏以"卡带插入"动效进入（过渡期间游戏动效冻结，就绪后开始）；返回大厅以"卡带退出"动效收起。
- **关气回流缩略**：CRT 关机坍缩演出中，游戏画面最后一帧截图在过曝亮线出现瞬间自原画面位置绽放缩飞、落回启动卡片并点亮辉光脉冲（总演出约 0.77 秒，衔接 0.55 秒关机动画窗口，「退出游戏 → 回到大厅」动效叙事闭环；「减少动态效果」偏好下不启动）。

#### H8 投币开机

- **目的**：以街机「投币启动」的仪式感开场，强化街机厅氛围，并自然完成浏览器音频解锁。
- **点亮前（待机态）**：大厅整体黑白灰度（星空 / 光晕 / 提示降饱和），游戏卡片锁定不可选；INSERT COIN 提示语与投币口保留霓虹色彩与呼吸动画，突出投币意图；音效与全屏按钮豁免灰度、外观与点亮后完全一致，随时可用。
- **触发**：点击屏幕任意处或按任意键即投币（音效 / 全屏控件与浏览器快捷键——Ctrl/Alt/Win 组合键、Tab、F 功能键——除外，防误触）；点亮后投币口或回车键可重复投币（纯装饰演出，可连点）。回车为投币专用键，不会误启动聚焦的游戏（启动游戏用空格 / 鼠标）；投币后的金币飞行与点亮过渡期（合计约 6.0 秒）内，同一手势触发的卡片点击也仅视为投币、不启动游戏。
- **投币演出**：金币于屏幕中央回弹放大展示（直径约 133px；币面为仿纪念币版式——「姜米条条的 / 像素街机厅」站名沿币缘弧形环排，上弧拱起、下弧正读，配珠点环 / 菱形饰 / 中央徽记，凹刻浮雕质感；展示期轻微摇摆、币面始终朝向观众，悬停约 1.15 秒供玩家看清铭文），末段蓄力胀起并迸发一圈金色光环，随后以抛物线拱顶逐渐缩小飞入投币口（飞行期金币自旋一周、翻面时铭文隐去露出素面币背，时长约 1 秒、弧顶随行程加高），投币口吞币演出（脉冲震颤 + 缝口金色闪光圈 + 金火花四溅 + 金属落箱吞币音）；首次投币于金币落入投币口的吞币瞬间点亮大厅。
- **点亮后**：金币吞入投币口后，大厅约 3.0 秒分层通电逐层亮起（模拟机台逐层上电）——层次感来自「离散事件 + 层间留白」：每一层均为一次快速脉冲式点亮（前半程快速过曝冲高、后半程沉降定色），前层亮完或接近亮完后层才接棒，绝不并排渐变糊成一片——环境电源层（星空 / 边缘光束 / 鼠标光晕）最先以两段脉冲点亮（继电器吸合 → 电压暂降 → 全压过曝 → 回落定色），随后副标题「啪」地亮起，ARCADE 标题按霓虹灯管点火规律「亮-熄-亮-熄-亮」三抽搐后稳定常亮（点燃的同时总分条通电），最后七张游戏卡片各经灰度点火幕帘自左向右错峰 0.15 秒快速逐张点亮（前一张将熄、下一张接棒，节拍清晰可数；幕帘退场伴随一道斜向电弧掠过），卡片解锁可选。
- **音效**：每次投币播放金属双音（首次投币与解锁双音同刻叠加，更醒耳），金币抵达投币口时另播金属落箱吞币音；静音时静默不出声。
- **减动效**：开启"减少动态效果"时仅出声、无金币飞行演出（见 R6）。
- **音频驱动灯带**：点亮后大厅环绕灯带与投币口随声音实时律动——低频能量驱动亮度与饱和（鼓点闪亮）、高频驱动色相流转，投币口随低音脉冲闪亮；静音或无声时自动回暗至基态；游戏覆盖层打开期间挂起、「减少动态效果」开启时禁用。

#### H9 成就奖杯墙与游玩时长统计

- **奖杯墙**：大厅右上角提供奖杯墙入口，点开聚合面板汇总六款有成就游戏的全部 25 项成就——每游戏一行展示「已解锁数 / 总数」与逐条达成状态，顶部进度环显示总体完成度；Esc 或点击面板外关闭。
- **游玩时长**：七款游戏累计统计游玩时长（页面可见期计时，隐藏挂起），于各游戏卡片角标显示累计分钟；时长仅存玩家本机。

### 4.2 贪吃蛇（snake）

- **目的与玩法**：操控蛇在场地中进食成长；撞墙或撞到自身即 Game Over。适用共享规则 R1~R6。
- **难度**：

| 档位 | 移动节奏（每步间隔） | 进食基础分 | 说明 |
| --- | --- | --- | --- |
| 无敌 | — | — | 不会死亡，供休闲练习 |
| 简单 | 200ms | 5 分 | |
| 中等 | 150ms | 10 分 | |
| 困难 | 100ms | 20 分 | |

- **计分与机制**：

| 机制 | 规则 |
| --- | --- |
| 金苹果 | 有 22% 概率出现限时特殊食物，存在 5 秒，分值为基础分 ×5 |
| 连击 | 3 秒窗口内连续进食形成连击，得分倍率 = 1 + 0.5 ×（连击数 − 1） |
| 提速 | 每进食 5 次，移动节奏 ×0.93 加速，下限 60ms |
| 每日目标 | 按本地日期确定性生成当日目标长度（15~30 节，同日恒定）；HUD 实时显示已达长度 / 目标，当日达成后记录当日达成标记（跨刷新保留） |

- **成就**：百分俱乐部 / 长蛇盘踞 / 连击好手（达成条件见《游戏说明》）。

### 4.3 俄罗斯方块（tetris）

- **目的与玩法**：操控七种方块在井内堆叠消行；适用共享规则 R1~R6。
- **计分规则**：

| 事件 | 得分 |
| --- | --- |
| 消 1 / 2 / 3 / 4 行 | 100 / 300 / 500 / 800 × 当前等级 × 难度倍率 |
| T-Spin（大 / Mini） | 400~1600 / 100~400（按消行数分档） |
| B2B（背靠背高难消行） | ×1.5 |
| All Clear（全清） | 800~2000（按消行数分档） |

- **核心机制**：

| 机制 | 规则 |
| --- | --- |
| 发牌 | 7-bag 随机（每袋七种方块各出现一次） |
| 锁定延迟 | 落地后 500ms 内可移动 / 旋转推迟锁定，同一方块最多推迟 15 次 |
| 输入手感 | 左右移带输入延迟与连发参数（DAS 150 / ARR 30），保证高速操作可控 |
| Hold | C / Shift 暂存当前方块，每种方块每轮一次 |
| 旋转 | Z 逆时针旋转 |
| 升级 | 每消 10 行升 1 级，下落节奏 −60ms，下限 80ms |

- **成就**：行云流水 / TETRIS！ / 高速运转。

### 4.4 吃豆人（pac）

- **目的与玩法**：在迷宫中吃光全部豆子过关；触碰幽灵损失一命。适用共享规则 R1~R6。
- **计分规则**：

| 事件 | 得分 |
| --- | --- |
| 普通豆 | 10 分 |
| 能量豆 | 50 分 |
| 反杀幽灵 | 连锁 200 / 400 / 800 / 1600 |
| 水果 | 100 × 关卡数，封顶 1000 |

- **核心机制**：

| 机制 | 规则 |
| --- | --- |
| 迷宫 | 19 × 21 经典布局 |
| 幽灵相位 | 每只幽灵按「散开 5s → 追击 18s」相位循环切换行为 |
| 出屋节奏 | 四只幽灵依次延迟 0 / 2 / 4 / 6 秒离开鬼屋 |
| 能量豆反制 | 能量豆生效期内幽灵可被反杀，反杀链在单次生效期内累计 |
| 水果 | 每关吃到第 70 / 170 颗豆时出现，存在 9 秒 |
| 奖励命 | 每累计 10000 分奖励 1 命（每局限一次） |

- **成就**：颗粒归仓 / 四连反杀 / 豆豆大胃王。

### 4.5 蜂群射击（bee）

- **目的与玩法**：波次制固定屏射击，抵御逐波增强的蜂群；每 5 波遭遇 Boss。适用共享规则 R1~R6，另设单局结算评级。
- **波次与 Boss**：

| 规则 | 数值 |
| --- | --- |
| 蜂群提速 | 每波移动速度 +12% |
| Boss 出现 | 每 5 波一场，带三段式入场演出 |
| Boss 血量 | 28 + 4 ×（波次 − 1） |
| Boss 击破奖励 | 500 + 50 ×（波次 − 1） |

- **道具系统**（击落掉率 9%，七选一）：

| 道具 | 效果 |
| --- | --- |
| 火力 W | 武器升级 |
| 护盾 S | 抵挡一次伤害 |
| 1UP ♥ | 奖励 1 命 |
| 炸弹 B | 范围清屏伤害 |
| 时停 T | 敌方静止 4 秒 |
| 磁铁 M | 吸附掉落物 6 秒 |
| 激光 L | 持续射线 5 秒 |

- **战斗机制**：

| 机制 | 规则 |
| --- | --- |
| 连击 | 2.5 秒窗口持续击落保持连击；每累计 5 连击倍率 +1，最高 ×5 |
| 冲刺 | 短距高速位移，冲刺中 0.16 秒无敌，冷却 1.6 秒 |
| 结算评级 | 按单局表现评 S / A / B / C |

- **成就**（10 项）：初战告捷 / 百人斩 / 十连击 / 连击大师 / 弑君者 / 十波坚守 / 万分俱乐部 / 爆破专家 / 幻影步 / 完美防御。

### 4.6 弹珠台（pinball）

- **目的与玩法**：物理弹珠台，3 球制；空格按住蓄力（至多 0.9 秒）发射。适用共享规则 R1~R6。
- **难度**：四档难度，逐档提升重力、缩短挡板长度并提高得分倍率（×1 → ×3）。
- **计分规则**：

| 事件 | 得分 |
| --- | --- |
| 弹柱 | 60 |
| 弹射器 | 25 |
| 目标灯 | 150 |
| 清空全部目标灯 | +2000 |
| JACKPOT | 5000 |

- **核心机制**：

| 机制 | 规则 |
| --- | --- |
| 连击 | 2 秒窗口内持续接触计分件保持连击；每累计 3 次倍率 +1，最高 ×5 |
| 多球 | 同屏最多 3 球；全部球落底才损失 1 球 |

- **成就**：头奖时刻 / 三球齐飞 / 两万分俱乐部。

### 4.7 华容道（klotski）

- **目的与玩法**：4×5 棋盘滑块解谜，将曹操（2×2）移至底部中央出口即通关；一次手势沿直线滑过几格计几步。适用共享规则 R1~R2、R5~R6（无成就系统，见下）。
- **布局**：六种经典布局——横刀立马 / 指挥若定 / 捷足先登 / 过五关 / 近在咫尺 / 兵临城下；数字键 1~6 直接切换。
- **难度**：

| 档位 | 辅助手段 |
| --- | --- |
| 新手 | 选中棋子显示可滑方向提示；U 撤销；H 提示无限次 |
| 进阶 | 标准规则；U 撤销；H 提示每局限 3 次 |
| 大师 | 禁用撤销与 H 提示 |

- **评级与纪录**：

| 规则 | 数值 |
| --- | --- |
| 通关评级 | 按 实际步数 ÷ 该布局最少步数 评级：≤1.15 S / ≤1.4 A / ≤1.8 B / 其余 C |
| 提示封顶 | 本局使用 H 提示 1~2 次最高评 A；≥3 次最高评 B |
| 纪录 | 按 难度×布局 分别记录最少步数与最高评级 |

- **特色功能**：

| 功能 | 规则 |
| --- | --- |
| 每日一题 | 按本地日期确定性地选定当日布局：同一天必同一题、跨日自动换题；侧栏按钮带「今」角标，当日通关计入当日成绩 |
| 演示 | P 键自动复现当前布局的最少步解（逐步播放，可中断）；演示通关走完整庆祝演出，但**不计入纪录与评级** |
| 求解 | 提示与演示由自动求解器在后台完成，主界面不卡顿；求解不可用时提示功能降级为不可用，游戏本身不受影响 |

- **操作**：拖拽滑块（跟手移动、松手吸附）或点击选中后用方向键推动；U 撤销 / R 重开 / H 提示 / P 演示 / 1~6 切布局 / 空格暂停。
- **设计决策——不设成就系统**：本作以「评级 + 最少步纪录 + 每日一题」承载长线追求目标，不另设成就。
- **快照特例**：切换布局同样清除快照（其余清除时机同 R1）。

### 4.8 数字合并 1024（n1024）

- **目的与玩法**：滑动合并同数字方块，目标合成 1024；棋盘满且无可合并即 Game Over。适用共享规则 R1~R6。
- **难度**：

| 档位 | 棋盘 | 撤销次数（每局） |
| --- | --- | --- |
| 简单 | 5 × 5 | 5 次 |
| 普通 | 4 × 4 | 3 次 |
| 困难 | 3 × 3 | 1 次 |

- **计分与机制**：

| 机制 | 规则 |
| --- | --- |
| 合并得分 | 每次合并得分为合并结果值（如 64+64 计 128 分） |
| 连击 | 连续有效合并维持连击，倍率 ×2 起步，此后每级 +10% ×（前序连击数） |
| 里程碑 | 首次合成 128 / 256 / 512 / 2048 / 4096 触发专属演出；≥2048 附带烟花庆祝 |
| 胜利面板 | 首次合成 1024 弹出胜利面板，可选择继续挑战更高数字 |
| 每日挑战 | 当日未达成时开局进入每日模式：方块生成序列按本地日期种子固定（同日每局同谜题），HUD 显示「每日挑战」徽章；当日首次合成 1024 即记录当日达成标记并庆祝 |

- **成就**：初窥门径 / 巅峰达成 / 百合并。

## 5. 共享规则与例外

以下 R1~R6 为全部游戏（除注明例外）共用的横切规则，是各游戏章节引用的唯一权威定义。

### R1 进度快照与断点续玩

- **写入时机**：对局进行中离开游戏时自动写入快照——包括①关闭覆盖层返回大厅（父页主动下发的保存通知，0.55s 关机动画窗口内送达）、②关闭 / 刷新页面（兜底）。二者的产品语义一致：**离开即存**。（2026-11-05 起游戏页无返回链接，原「游戏内返回链接 click」触发点随按钮移除而删除。）
- **恢复时机**：再次进入该游戏时校验快照：有效则摆出上次局面并提示「已恢复上次进度」；缺失或无效则正常新开局。
- **清除时机**：对局终结即清除——Game Over、通关、玩家主动重开。游戏特有清除断点（华容道切换布局）见该游戏章节。
- **数据边界**：快照仅存于玩家本机浏览器；清除浏览器站点数据即随之丢失，不产生任何网络传输。

### R2 暂停与恢复

- 空格键手动暂停 / 恢复（华容道同为空格；小蜜蜂例外——空格被持续射击占用，暂停固定 P 键）；
- 窗口失焦自动暂停，回到窗口不自动恢复（由玩家确认继续）；
- 暂停冻结一切计时、动画步进与局面变化，保证挂机 / 切窗不会虚增用时或污染纪录公平性；
- 暂停 / 恢复有独立音效反馈，BGM 挂起并在恢复时接续。

### R3 结算与纪录

- 对局终结弹出结算面板：展示本局得分、历史最高分（或最高评级 / 最少步纪录）、新纪录标记与破纪录演出（号角 / 琶音）；
- 结算时 BGM 停止；
- 结算面板支持一键重开下一局；
- 各游戏纪录按其维度持久保存（计分游戏按难度分记者以该游戏章节定义为准）。

### R4 成就

- 各游戏定义自己的成就集合（华容道不设成就，见 4.7）；
- 单局内达成即时弹出提示，达成状态跨局持久；
- 各成就的达成条件详见《游戏说明》对应章节，本文不重复。

### R5 音效行为

- 进入对局自动播放该游戏专属 BGM，结算或返回大厅时停止；
- **自适应分层**：各游戏按紧张度驱动 BGM 程序化叠加低音鼓点声部——贪吃蛇蛇身 ≥15 节 / 吃豆人幽灵追击相位 / 蜂群射击 Boss 战（警告演出即计入）为危险态，进入时鼓点层渐入、脱离危险态或对局终结后数拍内衰减消退；
- BGM / 音效全部由程序实时合成，不加载任何音频文件；
- 全部声音受 H4 的静音开关与双通道档位控制，状态跨页一致。

### R6 减动效与可访问性

- 系统开启"减少动态效果"（prefers-reduced-motion）时，演出类动效自动降级为简化呈现，不影响玩法与判定；
- 全部核心功能（大厅导航、各游戏玩法、暂停、静音、全屏）均可仅用键盘完成。

## 6. 约束与非功能需求

| 约束 | 要求 |
| --- | --- |
| 离线与零依赖 | 无构建步骤、无第三方运行时依赖、不请求任何外部网络资源；断网可完整游玩 |
| 本地数据边界 | 无账号体系；成绩、成就、偏好、进度全部仅存于玩家本机浏览器，不上传 |
| 性能 | 动画保持流畅；页面转入后台时随 R2 自动暂停，不空耗资源 |
| 平台 | 面向现代桌面浏览器与物理键盘 / 标准布局手柄（Gamepad API 即插即用）；移动端触屏不在承诺范围（华容道指针拖拽除外） |
| 文本选取 | 全站所有页面 body 级禁止文本选取（user-select: none），鼠标拖动不会框选界面文字、不会触发浏览器选中搜索 |
| 部署 | 静态文件即可部署，无服务端逻辑（实现附带禁缓存响应头的本地服务器示例，见《技术文档》） |
